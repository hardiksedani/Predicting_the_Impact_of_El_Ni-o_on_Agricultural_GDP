 
should move from representative points to documented state 
or crop -area summaries. Rolling -origin validation would 
show whether improvements persist across forecast origins, 
while a separate state -transfer experiment could assess 
generalization beyond the fitted state vocabulary. Each 
extension should be compared with persistence using data 
available at the intended prediction date. This sequence 
would strengthen the connection between the application's 
outputs and the agricultural questions it is intended to 
support.
